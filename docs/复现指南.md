# 复现指南

> 从零复现本项目（RAG → SFT → DPO → 安全评测）的完整步骤
> 环境：MacBook Pro M4 Pro / 24GB / macOS

---

## 0. 总览

```
环境准备 → 数据准备 → SFT 训练 → 合并 adapter → DPO 训练 → 功能评测 → 安全评测
```

每个阶段产出一个可验证的产物，建议按序执行。

---

## 1. 环境准备

## 3. SFT 训练（项目三）

### 3.1 准备基座模型

```bash
# 下载 Qwen2.5-1.5B-Instruct HF 格式（项目四用）
huggingface-cli download Qwen/Qwen2.5-1.5B-Instruct --local-dir models/Qwen2.5-1.5B-Instruct-hf
```

### 3.2 训练

```bash
# MLX 环境
source .venv/bin/activate
uv run python scripts/train_sft.py
```

推荐参数：200 steps，学习率 1e-5，LoRA r=8。

### 3.3 产出

```text
hf_sft_v4_boundary_output/checkpoint-200/
```

## 4. 合并 SFT adapter（项目四前置）

```bash
# PyTorch 环境
source .venv-dpo/bin/activate

# 合并 SFT adapter 到 HF 基座
uv run python scripts/merge_sft_adapter.py
```

产出：

```text
hf_sft_v4_merged/
```

> 这是关键步骤：DPO 必须在 **SFT 合并后的模型** 上做，不能在基座上做（实测角色会退化）。

## 9. 常见问题

### Q1: MPS 报 pin_memory 警告
不影响训练，忽略即可。

### Q2: 训练报显存不足
- 减小 batch size 到 1
- 开启 gradient_checkpointing
- 使用 fp16

### Q3: DPO 报 max_prompt_length 错误
明确设置 `max_length`（如 512）和 `max_prompt_length`（如 384）。

### Q4: 向量存储超限（Dify）
Parent-Child 分片双倍占用存储，控制文档规模或精简数据。
